---
title: "Test users"
description: "Try your plugin as a user would, before you publish and before every change, without paying."
---

A test user is an account with you that you designate by email on a plugin's **Test** page. It sees the version you choose, its purchases are simulated, and its usage counts for nothing. Use one to try signup, premium features, upgrades, and billing changes exactly as a user would.

## Setting up a test user

Click **New test user** on the Test page, enter an email, and choose its settings.

- **Version** is either your current draft, to test changes before you publish them, or production, to test your published version.
- **Starting state** is whether the test user starts out not signed up or on one of your plans. **Reset test user** puts them back in it whenever you want to start over.
- **Saved payment method** is whether they start with a card on file.

Adding an email that already has an account with you turns that account into a test user, in the starting state you choose.

## Testing

Click **Test as user** to open your plugin's pages as the test user. Everything works as it would for a real user, from signup to checkout and billing, and nothing is charged. A pricing page on your own site shows the test user's version too, when your site shares a domain with the plugin's pages, like `coolplugin.com` and `get.coolplugin.com`.

To test in an AI product, run the `plugpass-test-plugin` skill from your plugin's directory in Claude Code or Codex. It helps you install a test version of your plugin on the AI product you choose, and gives you a link that puts your browser into test mode for the test user you pick. When you're done testing, tell your agent or run the skill again with `done` to switch back to your real plugin.

If your plugin runs its own MCP server, deploy your implemented changes to it before you test in an AI product, as [Your own MCP server](/your-mcp-server) describes.

## Reviewer test users

Every plugin has an Anthropic reviewer test user and an OpenAI reviewer test user. When you submit your plugin to the Claude Plugin Directory or the ChatGPT Plugin Directory, give the directory's reviewers the matching test user's login from **Copy login info**. Reviewers can use every premium feature of your published plugin, with no limits.

To give another plugin directory's reviewers a login, add a test user with the **Reviewer** user type.

## What test users don't affect

Test users are left out of your analytics, your user sync webhook, and your usage reports. Their simulated subscriptions never reach Stripe.
